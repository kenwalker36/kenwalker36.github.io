# MYSPACE 复古个人网站

参考 2012 年前后 g-cores.com 的黑色背景、灰色面板、橙红色按钮和双栏布局制作。所有示例文字、图形和个人标识均为本原型新建，未复制机核文章、用户资料或品牌图片。

## 直接打开

双击 `index.html`，即可在浏览器中使用，无需安装软件，也不依赖外部字体、脚本或网络图片。请保留同目录下全部网站文件。

当前为工业科幻风格，由 theme-industrial.css 控制：炭灰绿、浅灰绿、荧光黄及少量安全橙。移除 index.html 中对 theme-industrial.css 的引用，即可恢复最初的黑灰橙红风格。theme-purple.css 为未加载的备用主题。

## 替换成你的内容

- `content.js`：修改姓名、个人介绍、公开邮箱、文章和作品。文章正文按段落写进 `body` 数组。新增内容时保持 `id` 唯一。日期使用 YYYY-MM-DD。作品的 `url` 可填公开项目的 https 地址，留空时隐藏按钮。
- `index.html`：修改站点名 MYSPACE、左侧简介、页脚及 SEO 描述。站点名目前是临时标识，可自由改名。
- `style.css`：修改颜色和样式，`--orange` 是强调色。当前作品封面为 CSS 示例图，可将 app.js 的 `art()` 函数改为使用本地 `<img>`，并配置对应图片路径。
- `app.js`：页面切换、搜索、作品分类、轮播按钮和文章弹窗逻辑。

## 目前包含

首页、文章归档、文章分类、全文关键词搜索、作品展示与分类筛选、文章/作品阅读弹窗、个人介绍、手机适配。按 Esc 或点关闭可退出阅读。

## 上线方式

这是静态网站，可把整个文件夹上传到支持静态托管的平台，如 GitHub Pages、Cloudflare Pages 或 Netlify，之后绑定自己的域名。当前尚未部署。中国大陆服务器及域名使用要求取决于你选择的服务商。

这一版没有后台、账号、评论或数据库。发布文章需要编辑 content.js 并重新上传。后续若需要浏览器后台写作、图片上传或评论，可在确定托管方式后添加 CMS 或改成带后台的版本。文章阅读使用 # 链接，适合简单个人站；若注重每篇文章的搜索引擎收录，下一版适合改为独立文章页面或静态站点生成器。
